# wyfang.github.io

王一方的个人主页，用一个静态页面汇集个人身份、社交平台与长期维护的站点入口。

[访问网站](https://wangyifang.com) · [更新记录](https://blog.wangyifang.com/mywebupdate/)

![网站预览](./share/img/201904281548.png)

## 特性

- 响应式布局与自动深色模式
- 程序化动态头像与静态降级
- 社交平台入口、好友码与二维码展示
- 无框架静态部署
