Wi-Fi 自定义宠物

一个宠物就是一个文件夹。文件夹名会显示在 Wi-Fi 的宠物菜单里，放入序列图后即可被识别。

放在哪里

macOS

~/Library/Application Support/com.wangyifang.Wi-Fi/pets/custom/

Windows

%LOCALAPPDATA%\com.wangyifang.Wi-Fi\pets\custom\

最小文件结构

我的宠物/
  spritesheet.webp

支持 spritesheet.png、spritesheet.webp、spritesheet.gif、spritesheet.jpg、spritesheet.jpeg。 如果没有 config.json，Wi-Fi 会使用默认配置。

可选 config.json

{
  "spritesheet": "spritesheet.webp",
  "frame": { "width": 192, "height": 208 },
  "scale": 0.5,
  "fps": 12,
  "priority": 10,
  "animations": {
    "default": { "row": 1, "frames": 8, "fps": 6, "mode": "once" },
    "hover": { "row": 1, "frames": 6, "fps": 6, "mode": "once" },
    "dragLeft": { "row": 3, "frames": 8, "fps": 8, "mode": "loop" },
    "dragRight": { "row": 2, "frames": 8, "fps": 8, "mode": "loop" }
  }
}

row 从 1 开始。priority 越小，菜单排序越靠前。

制作建议

  • 每一帧尺寸保持一致，例如 192×208。
  • 透明背景能让宠物看起来更自然。
  • 鼠标命中区域可以使用 interaction.hitMaskRow 指定专用行。
  • 替换文件后重新打开宠物菜单，Wi-Fi 会重新扫描本地自定义宠物。
